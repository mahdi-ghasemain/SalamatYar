# سلامت‌یار / SalamatYar

> **به‌روزرسانی ۳۰ سپتامبر:** اتصال Supabase، ورود ایمیلی/گوگل، مدارک خصوصی، نقشه واقعی، اسکن بارکد، بازیابی پشتیبان و یادآوری نوبت اضافه شده‌اند. راهنمای جاری و محدودیت‌های فعال‌سازی در [SETUP-FA.md](SETUP-FA.md) است. توضیحات نسخه اولیه در ادامه، سابقه مرحله قبل است و برای وضعیت سرویس‌های جدید به راهنمای جاری مراجعه کنید.

نسخه اولیه اپ اندروید با React Native، Expo SDK 57 و TypeScript. رابط فارسی راست‌به‌چپ و انگلیسی چپ‌به‌راست؛ بدون نیاز به شماره تلفن ایرانی یا خدمات ورود گوگل.

## اجرا

```sh
npm install
npm start
```

برای پیش‌نمایش مرورگر: `npm run web`. برای دستگاه یا شبیه‌ساز اندروید: `npm run android` با محیط اندروید آماده. اعلان واقعی باید روی دستگاه آزمایش شود.

## ساخت خروجی اندروید

```sh
npx eas-cli@latest login
npx eas-cli@latest build --platform android --profile preview
```

پروفایل preview خروجی APK و production خروجی AAB می‌سازد. ایجاد خروجی ابری به حساب Expo، اینترنت و تنظیم امضای اندروید نیاز دارد. هیچ حساب، کلید امضا یا انتشار فروشگاهی در این پروژه انجام نشده است. پیش از انتشار مالکیت شناسه `com.salamatyar.care` باید بررسی شود.

## امکانات موجود

- زبان فارسی و انگلیسی؛ تقویم شمسی یا میلادی برای نمایش تاریخ‌ها.
- پروفایل‌های محلی خانواده با تأیید رضایت.
- ثبت دارو و یک ساعت مصرف روزانه، دستور مصرف واردشده توسط کاربر، موجودی، ثبت مصرف و لغو ثبت.
- اعلان محلی روزانه با فعال‌سازی جداگانه هر دارو و محتوای عمومی روی صفحه قفل.
- ثبت نوبت و یادداشت سلامت برای هر پروفایل.
- ذخیره محلی داده‌ها و نمایش خطای خواندن/نوشتن.
- شروع با اطلاعات خالی، بدون دارو یا نسخه فرضی.

## حدود نسخه اولیه

این نسخه آماده استفاده عمومی با داده واقعی پزشکی نیست. ذخیره محلی رمزگذاری اختصاصی ندارد؛ فعلاً از داده آزمایشی استفاده کنید. پشتیبان‌گیری خودکار اندروید غیرفعال است. ورود امن، رمزگذاری، قفل زیستی، پشتیبان‌گیری و بازیابی، همگام‌سازی خانوادگی، حذف/ویرایش کامل، پیوست مدارک و ورود تاریخ شمسی هنوز پیاده‌سازی نشده‌اند. ورود تاریخ فعلاً میلادی است و پیش‌نمایش آن با تقویم انتخابی نشان داده می‌شود.

هر رکورد دارو یک نوبت در روز و یک واحد موجودی دارد. برنامه‌های پیچیده، داروی موردنیاز، محاسبه دوز و تغییر نسخه پشتیبانی نمی‌شوند. اعلان‌ها تابع مجوز و محدودیت باتری اندروید هستند؛ هیچ تضمین زمانی داده نمی‌شود. نوبت‌ها اعلان ندارند. شمارش مصرف تنها گزارش کاربر است.

طراحی مستقل از خدمات ابری و پرداخت، شروع را برای ایران و کاربران بین‌المللی ممکن می‌کند؛ آمادگی قانونی/فروشگاهی یا عرضه در کشورها تأیید نشده است.
